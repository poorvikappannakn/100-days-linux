# Week 07 – Command Documentation & User/Group Management

## 📖 Overview

This week focused on understanding how Linux identifies commands, using built-in documentation, and managing users and groups. I learned the difference between built-in and external commands, explored manual pages, searched documentation with `apropos`, and practiced basic Linux group administration.

---

## 📚 Topics Covered

- Built-in vs External Commands
- Using the `type` command
- Reading Linux manual pages (`man`)
- Searching commands with `apropos`
- Creating groups using `groupadd`
- Adding users to groups with `usermod`
- Managing group membership using `gpasswd`
- Understanding the `/etc/group` file

- Improved command discovery using `man` and `apropos`.
- Practiced creating and managing Linux groups.
- Understood how users are added to and removed from groups.
