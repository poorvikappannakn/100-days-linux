# 100 Days of Linux 🐧

A hands-on Linux learning journey focused on building strong command-line, system administration, and scripting fundamentals through consistent practice and documentation.

This repository contains my weekly Linux learning notes, practical exercises, and command-line experiments.

---

## 🎯 Goals

* Build strong Linux fundamentals
* Become comfortable working in the terminal
* Understand Linux users, groups, permissions, and access control
* Develop Bash and shell scripting skills
* Learn practical Linux text-processing and system-management workflows
* Build a strong foundation for cybersecurity-related work

---

## 📚 Weekly Learning Progress

### Week 01 – Linux Fundamentals & File Operations

Learned the basics of the Linux filesystem, terminal navigation, file and directory operations, paths, hidden files, and Linux file permissions.

### Week 02 – Users, Groups & Shell Scripting

Learned Linux user and group management, account-related files, sudo access, password/account locking, and the basics of Bash scripting including shebangs, quoting, and script execution.

### Week 03 – Logs, System Information & Shell Operators

Practiced system information and process monitoring, kernel messages and log searching, file archiving, output redirection, pipelines, and combining commands to create simple system reports.

### Week 04 – Terminal Utilities

Explored terminal utilities for ASCII-art generation, date and calendar information, arithmetic calculations, and maintaining a clean terminal workspace.

### Week 05 – Linux Workflows & Command-Line Productivity

Practiced filesystem organization, safe file-review workflows, project workspace management, Linux help/documentation, terminal shortcuts, and wildcard pattern matching.

### Week 06 – File Handling & Text Processing

Learned how to work with filenames containing spaces, edit files using Nano, and practice text-processing utilities such as `sort` and `uniq`.

### Week 07 – Command Documentation & Group Management

Learned how Linux identifies commands, how to use built-in documentation and manual pages, and how to create and manage groups and group membership.

### Week 08 – Password Management & Text Extraction

Learned user and group password management and practiced extracting fields from structured, delimiter-based text using `cut`.

### Week 09 – Filesystem Utilities & File Viewing

Reinforced user/group management and filesystem navigation while practicing directory utilities, file viewing, line numbering, word counting, and combining commands for targeted searches.

### Week 10 – Advanced Text Processing & File Comparison

Expanded Linux text-processing skills through searching, file locating, field extraction, sorting, character translation, custom commands, regular expressions, and comparing files and directories.

### Week 11 – Data Processing, Automation & System Monitoring

Practiced `join`, `xargs`, and `awk` for structured data processing and command automation, along with pipelines, log analysis, process monitoring, memory usage, disk usage, and identifying large files.

### Week 12 – Permissions & Access Control

Practiced testing Linux permissions as another user and worked with file and directory access, ownership, groups, unsafe permissions, restoring access, and auditing access.

### Week 13 – Bash Variables & Scripting

Learned shell variables, variable expansion and quoting, command substitution, arithmetic operations, environment variables, variable scope, command-line arguments, shell arrays, and basic use of Vi/Vim and Nano.

### Week 14 – Shell Environment & Configuration

Learned about environment variables and inheritance, child shells, process IDs, shell aliases, shell options, `allexport`, `SHELLOPTS`, and persistent Bash/Zsh configuration.

### Week 15 – Redirection, Links & User Management

Learned standard input/output/error redirection, appending and capturing command output, `tee`, hard and symbolic links, inode concepts, switching between users, password aging, group management, and user account removal.

This journey focuses on **hands-on learning rather than only memorizing commands**.
