# Week 10 – Linux Text Processing and File Comparison

This week focused on Linux text processing utilities used to search, extract, manipulate, sort, transform, and compare text files. These commands are widely used in Linux administration, shell scripting, log analysis, and data processing.

## Topics Covered

### File Searching & Custom Commands
- `which`
- `whereis`
- `find`
- `locate`
- Creating custom commands
- Understanding the `PATH` environment variable

### Text Searching
- `grep`
  - Case-sensitive and case-insensitive search
  - Whole-word matching
  - Inverted search
  - Counting matches
  - Recursive search
  - Displaying line numbers
  - Searching multiple patterns
  - Regular expressions

### Field Extraction
- `cut`
  - Delimiter-based extraction
  - Character position extraction
  - Multiple field extraction
  - Range extraction
  - Fixed-width fields
  - Skip lines without delimiters
  - Combining `cut` with `grep`

### Sorting Data
- `sort`
  - Alphabetical sorting
  - Numerical sorting
  - Reverse sorting
  - Field-based sorting
  - Multiple-key sorting
  - Removing duplicate entries
  - Common sorting options

### Character Translation
- `tr`
  - Uppercase to lowercase conversion
  - Lowercase to uppercase conversion
  - Character replacement
  - Character deletion
  - Character classes
  - Squeezing repeated characters
  - Truncating translation sets

### Comparing Files
- `diff`
  - Basic file comparison
  - Understanding add, delete and change operations
  - Unified output format
  - Ignoring whitespace changes
  - Comparing directories recursively
