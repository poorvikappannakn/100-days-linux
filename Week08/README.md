# Week 08 – Password Management & Text Processing

## Overview

This week focused on Linux password management and basic text processing. I learned the difference between user and group passwords, explored the `passwd` and `gpasswd` commands, and practiced extracting fields from delimited text using the `cut` command.

## Topics Covered

- User Password Management
- Group Password Management
- `passwd`
- `gpasswd`
- Delimiters
- `cut` command

## Files

| File | Description |

| `text-processing-with-cut.md` | Understanding delimiters and extracting fields using the `cut` command. |

## Commands Practiced

```bash
passwd
gpasswd
cut
```

## Key Takeaways

- Learned the difference between user and group passwords.
- Practiced managing users and groups using `passwd` and `gpasswd`.
- Learned how delimiters work.
- Used `cut` to extract specific fields from text files.
