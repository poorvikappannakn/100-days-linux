# Date and Time Commands

## date

Displays the current system date and time.

### Syntax

date

### Example Output

Mon Nov 25 01:48:53 PM CST 2025

### Learning

* View current date and time
* Check system clock
* Verify timezone settings

---

## cal

Displays a calendar in the terminal.

### Syntax

cal

### Example

cal

Displays the current month.

### Display a Specific Year

cal 2025

### Learning

* View monthly calendar
* View yearly calendar
* Understand date-related utilities
