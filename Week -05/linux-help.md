# Linux Help Commands

## --help

Displays a quick summary of a command.

### Example

```bash
ls --help
```

---

## man

Displays the complete manual page.

### Example

```bash
man ls
```

---

## Difference

| Command | Purpose |
|----------|---------|
| --help | Quick reference |
| man | Detailed documentation |

---

## Learning Outcome

- Read Linux documentation
- Understand command usage
- Learn command options
