# Terminal Productivity Shortcuts

## Arrow Up (↑)

Recalls previously executed commands.

---

## Tab

Auto-completes commands and filenames.

Example:

```bash
cat hel<Tab>
```

becomes

```bash
cat hello.txt
```

---

## Ctrl + C

Stops a running command.

---

## Ctrl + L

Clears the terminal screen.

---

## Learning Outcome

- Faster navigation
- Reduced typing
- Improved command-line efficiency
