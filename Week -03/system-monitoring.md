# System Monitoring

## Commands Practiced

```bash
uname
uname -a
uptime
nproc
id
top
```

---

## uname

```bash
uname
```

Displays the current kernel name.

Example:

```text
Linux
```

---

## uname -a

```bash
uname -a
```

Displays:

- OS name
- Hostname
- Kernel version
- Hardware architecture

---

## uptime

```bash
uptime
```

Displays:

- Current time
- System uptime
- Logged-in users
- Load averages

Example:

```text
up 22 days, 17:57, load average: 0.20, 0.30, 0.22
```

Load averages represent system load over:

- 1 minute
- 5 minutes
- 15 minutes

---

## nproc

```bash
nproc
```

Displays the number of CPU cores available.

---

## id

```bash
id
```

Displays:

- UID (User ID)
- GID (Group ID)
- Supplementary groups

---

## top

```bash
top
```

Provides a real-time view of:

- CPU usage
- Memory usage
- Running processes
- System load

Exit:

```text
q
```

---

## Key Learnings

- Learned how to inspect system information.
- Monitored uptime and load averages.
- Retrieved user and group details.
- Used top for real-time monitoring.
