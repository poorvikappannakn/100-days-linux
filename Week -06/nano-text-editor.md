# Nano Text Editor

## Overview

Nano is a terminal-based text editor used to create and modify text files directly from the command line.

---

## Opening a File

```bash
nano "client status.txt"
```

---

## Editing

Example:

```
client=northwind
status=pending
contact=unset
```

Updated to:

```
client=northwind
status=approved
contact=ops-team
```

---

## Common Shortcuts

| Shortcut | Function         |
| -------- | ---------------- |
| Ctrl + O | Save file        |
| Enter    | Confirm filename |
| Ctrl + X | Exit editor      |
| Ctrl + K | Cut line         |
| Ctrl + U | Paste line       |

---

## Learning Outcome

* Edit configuration files.
* Save changes from the terminal.
* Modify text without a graphical editor.
